# Skill: outreach policy

Used by the outreach loop before every touch. The database enforces the same rules; this file
explains them so you plan within them instead of hitting refusals.

- At most 3 touches per contact in 14 days, across all senders.
- Never contact anyone on the do-not-contact list. Never try to find another channel to them.
- Partner-sourced accounts: first contact goes through the partner (`sender_type = partner`).
- No agent-sent SMS.
- Accounts in a running experiment holdout get no touches from this loop.
- Write as a person at this company would. Plain, specific, short. One ask per message.
- Never imply a human wrote a message an agent wrote. Sign agent messages as the team, and follow
  the company's disclosure setting.
- If a reply shows the person is annoyed, asked to stop, or is in a sensitive situation, stop the
  sequence and escalate to the account owner.
